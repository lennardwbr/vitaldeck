# VitalDeck

Landingpage und Warteliste für **VitalDeck**: Coach, Trainingsplan, Strecken und Auswertungen für deine Garmin-Daten, auf deinem eigenen Server.

Die Seite ist statisch und läuft ohne Build-Schritt auf GitHub Pages.

- `index.html`: Landingpage auf Deutsch und Englisch (Umschalter oben rechts, `?lang=en` erzwingt Englisch)
- `impressum.html`, `datenschutz.html`: Rechtliches
- `fonts/`: selbst gehostete Schriften (Bricolage Grotesque, Atkinson Hyperlegible Next, SIL Open Font License), damit keine Anfragen an Google gehen
- `img/`: Screenshots der App mit Beispieldaten

Die Warteliste läuft über Formspree. Ohne Cookies und ohne Tracking.
